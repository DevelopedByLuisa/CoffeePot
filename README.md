# CoffeePot
CoffeePot is an application designed to digitize the traditional office beverage tally sheet. It allows you to manage your products, record purchases, keep track of consumption and settle outstanding balances with your colleagues.  

Instead of maintaining a handwritten list in the office kitchen, CoffeePot provides a central place to manage everything related to shared beverages.

## Features
- Manage products and their prices
- Record purchases and consumption
- Keep track of individual balances
- Settle outstanding amounts with colleagues
- View and manage transaction history
- Manage shared office beverages in one central place

## Tech Stack
### Backend
- .NET 10
- Entity Framework Core
- Swagger/OpenAPI

### Frontend
- React
